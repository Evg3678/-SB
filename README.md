# Дашборд SB — тестовый стенд

Аналитика синтетических логов LLM: ручная загрузка XLSX/CSV, фильтры, графики и автономный HTML-отчет.

**Не загружайте реальные корпоративные логи, персональные данные, пароли и ключи.**
Загружаемые файлы обрабатываются на сервере приложения в памяти сессии, а не исключительно в браузере. Приложение не записывает исходные логи на диск. Скачанные отчеты содержат данные выбранной сессии.

## Публикация в Streamlit Community Cloud

1. Войдите в https://share.streamlit.io/ и подключите этот репозиторий.
2. Репозиторий: `Evg3678/-SB`, ветка: `main`, основной файл: `app.py`.
3. Выберите Python 3.12 или 3.13. Зависимости устанавливаются из `requirements.txt`.
4. Запустите Deploy. Используйте фактическую ссылку, выданную хостингом.

Приложение не требует ключей или secrets. Публичная ссылка не является контролем доступа.
GitHub содержит код; сам Python-сервер запускается на хостинге, не в GitHub Pages.

## Локальный запуск

Создайте `.venv` командой `python -m venv .venv`, затем установите зависимости:
`.venv\Scripts\python.exe -m pip install -r requirements.txt`.
На Windows запустите `start.bat`: он явно ограничивает доступ адресом `127.0.0.1:8504`.
Сетевой адрес и порт намеренно не заданы в общей конфигурации, чтобы их определял хостинг; для локальной работы используйте `start.bat`.

Время запросов и фильтрация по дням: Москва (UTC+3). Темы: меню ⋮ → Light / Dark.
Вкладки: Обзор, Сотрудники, Модели, Детализация и Отчёт. Загрузка и связанные фильтры находятся в боковой панели; email и ID — в дополнительных фильтрах. Кнопка сброса очищает все фильтры и восстанавливает полный период.
Списки ID раскрываются отдельно от основных таблиц и полностью сохраняются в CSV и HTML. Расходы в верхней карточке округлены до копеек только для отображения; исходная точность в выгрузках не меняется.
Отсутствующая стоимость не считается нулевой; такие вызовы учитываются в запросах, токенах и задержках.

## Проверка

`python -m unittest test_sb test_ui -v`

Опциональная локальная проверка XLSX: переменная окружения `SB_SAMPLE` с путем к файлу. Сам файл в репозиторий не включается.
